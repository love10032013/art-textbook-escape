# 교과서 속 미술관 방탈출

정적 웹사이트입니다. 폴더를 로컬 HTTP 서버로 열거나 GitHub Pages에 업로드합니다. `index.html`, `style.css`, `app.js`, `assets/`가 필요합니다. Three.js는 포함되어 있으며 글꼴은 인터넷에서 불러옵니다.

마우스로 드래그하여 둘러보고 바닥을 클릭해 이동합니다. 소리는 사용자가 켠 후 재생됩니다. 관리자 모드는 5852입니다. 정적 사이트이므로 관리자 비밀번호와 답은 소스에서 확인할 수 있습니다.

교과서 캡처에서 작품 부분을 잘랐습니다. 외부 공개 전에 교과서 및 작품 이미지의 이용 권한을 확인하세요. 원본 캡처의 일부 작품은 해상도가 낮습니다.


## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 `index.html`, `style.css`, `app.js`, `assets` 폴더를 저장소의 기본 브랜치 루트에 업로드합니다. 교과서 원본 캡처와 `crop_assets.py`는 배포에 필요하지 않습니다.
2. 저장소의 Settings → Pages에서 배포 소스를 `Deploy from a branch`, 브랜치를 기본 브랜치와 `/ (root)`로 설정합니다.
3. 표시되는 Pages 주소에서 게임을 열어 확인합니다.
